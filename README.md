# 台股投資分析平台

個人用台股分析工具，分析邏輯以 [台股投資分析實戰框架.md](台股投資分析實戰框架.md) 為藍本。
純本機運行、免費資料來源、資料庫單檔（`data/stocks.db`）。

> 本工具僅供個人研究，不構成投資建議；下單請自行於券商 App 執行。

## 啟動

```bash
uv run uvicorn app.main:app --port 8787
```

瀏覽器開 <http://localhost:8787>。

## 首次使用（資料初始化）

到「儀表板 → 資料維護」依序按：

1. **同步股票清單** — 全市場 2,700+ 檔股票/ETF 主檔（幾秒）
2. **更新今日行情** — 全市場收盤、估值、法人、大盤（約 30 秒）
3. **回填 180 天歷史** — 供均線、法人連買篩選（背景執行 10-15 分鐘，可中斷續跑）
4. **抓全市場月營收** — 供營收類篩選（背景執行約 2 分鐘）

## 每日資料如何更新

平日 15:05 會嘗試自動更新（每月 10-12 日自動抓月營收），**但這是伺服器 process 內建的排程，只有在 process 持續活著時才會準時觸發**。筆電闔上/睡眠會讓排程被跳過（APScheduler 的 misfire 機制：錯過超過約 1 小時就直接放棄，不會補跑）。

因此不用去背排程時間——**每次打開儀表板時，系統會自動比對「最新資料日期」跟「應該已收盤的最近交易日」，資料過期就會跳出橘色提示條，點一下「立即更新今日行情」補更新即可**。此判斷只看平日/週末，不知道國定假日，遇到國定假日出現提示是正常的，忽略即可。

## 功能對映框架

| 頁面 | 功能 | 框架章節 |
|---|---|---|
| 儀表板 | 大盤、法人金額、市場寬度、觀察名單速覽 | 二之1 大盤與總體 |
| 個股頁 | K線均線、月營收、獲利能力、財務品質、估值、籌碼 六面向 | 二之2~7 |
| 個股頁右欄 | 100 分評分表（量化自動預填＋質化人工）、警訊、治理查核清單 | 四、五 |
| 篩選器 | 全市場掃描（營收動能/轉機/價值存股/突破），命中自動預抓深度資料 | 三之2 中期波段 |
| 觀察名單 | 研究中/等買點/持有中 三級，盤中準即時報價（約 5 秒延遲） | 七之4 等待買點 |
| 交易日誌 | 買進前八句話、最大虧損反推部位、持倉損益、勝率與盈虧比 | 六、三之3 |

## 資料來源（全部免費）

- **證交所 OpenAPI / 官網 JSON** — 全市場收盤、估值、三大法人、大盤（輕量層，每日 6-8 個請求）
- **櫃買中心 OpenAPI / 官網 JSON** — 上櫃對應資料
- **FinMind** — 個股深度資料：5 年價量、月營收、三大財報、法人/融資券、股利（按需抓取）
- **MOPS 公開資訊觀測站** — 全市場月營收彙總（每月 2 個請求）
- **證交所 MIS** — 盤中準即時快照（無金鑰時的後備，約 5 秒延遲、限速輪詢）
- **富果 Fugle 行情 API**（選用）— 設定金鑰後自動升級為真即時逐檔報價，取代 MIS 快照

### FinMind 金鑰（建議但非必要）

到 <https://finmindtrade.com> 免費註冊取得 token（600 次/小時），在專案根目錄建 `.env`：

```
FINMIND_TOKEN=你的token
```

不填也能用，但深度抓取額度較低。

## 架構要點

- **三層資料策略**：全市場輕量層（每日全表、永遠在庫）→ 個股深度層（開頁/加觀察/篩中才抓，12 小時內視為新鮮）→ 清理層（非觀察名單 90 天未存取可釋放）
- **行情可插拔**：`app/datasources/realtime_base.py` 定義介面；有 `FUGLE_API_KEY` 就自動用富果真即時，否則退回 MIS 快照（金鑰失效時也會自動降級，不會整個報價功能掛掉）
- **上雲預留**：設定走環境變數、SQLAlchemy Core（可換 Postgres）、無本機路徑硬編碼

## 富果即時行情金鑰

到 <https://developer.fugle.tw> 申請行情 API 金鑰，寫入 `.env`：

```
FUGLE_API_KEY=你的金鑰
```

免費方案為逐檔查詢（實測限速 60 次/分鐘），觀察名單按「更新盤中報價」時會依序查詢每一檔。
`.env` 已加入 `.gitignore`，不會被提交或外洩。

## 測試

```bash
uv run python tests/smoke.py            # 全部：資料源 + 輕量層 + 深度層
uv run python tests/smoke.py sources    # 只測資料源
```

## 交易成本設定（.env 可覆寫）

```
FEE_DISCOUNT=0.6   # 手續費折數（預設 6 折）
TAX_RATE=0.003     # 證交稅（ETF 請自行改 0.001）
```
