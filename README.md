# 台股投資分析平台｜使用手冊

這是一套個人用的台股研究工具，協助你從市場與個股分析、策略回測，一路整理到投資組合、交易紀錄與長期財務規劃。**平台只做分析、研究與記錄，不會連接券商下單。**

本手冊說明目前網站的使用方式。開發指令、資料來源設定與回補工具見 [開發與資料維護參考](docs/DEVELOPMENT.md)；功能進度及限制見 [專案狀態](docs/PROJECT_STATUS.md)；其他文件由 [文件導覽](docs/README.md) 查找。

> 歷史研究結果與財務試算都不是未來報酬保證，也不構成投資建議。實際交易請自行在券商執行，再回來記錄成交。

## 1. 開啟網站

### 私人雲端版

開啟 [Railway 網站](https://stocks-production-eeb3.up.railway.app)。最後驗證的雲端版本仍使用共用 HTTP Basic 帳密及資料；**本次帳號系統尚未遷移／部署到 Railway**，不能先把該共用帳密交給朋友使用。

新程式採邀請制：管理員在「帳號與存取」建立邀請，朋友自行設定密碼。每人的財務規劃、持股、筆記及策略研究分開，行情共用；朋友不能操作全站資料維護。修改密碼與登出也在「帳號與存取」；忘記密碼請向管理員索取重設連結。初始化、復原與上線步驟見 [帳號說明](docs/ACCOUNTS.md)。

### 本機版

先依 [帳號說明](docs/ACCOUNTS.md) 停止舊服務、備份並初始化管理員一次；已準備好環境及帳號後，在專案資料夾執行：

```bash
STOCKS_COOKIE_SECURE=0 uv run uvicorn app.main:app --port 8787
```

再用瀏覽器開啟 <http://localhost:8787>。首次安裝或環境設定請參考 [開發文件](docs/DEVELOPMENT.md)。本機服務需要保持執行，關閉終端機或電腦睡眠會中斷背景工作與排程。

**本機與雲端是兩份獨立資料庫，不會自動同步。** 新增觀察名單、交易紀錄或財務情境前，先確認自己開的是哪一個版本。

## 2. 從哪裡開始

| 想做的事 | 使用頁面 | 建議操作 |
|---|---|---|
| 瞭解市場、確認資料日期 | 儀表板 | 先看資料狀態，再看大盤、法人與市場寬度 |
| 找符合條件的股票 | 篩選器 | 選預設條件或自行設定，執行後開啟個股 |
| 研究一家公司 | 個股頁 | 搜尋代號／名稱，查看六個面向並補上自己的判斷 |
| 持續追蹤股票 | 觀察名單 | 分成研究中、等買點、持有中，留下追蹤筆記 |
| 驗證策略 | 策略實驗室 → 參數穩健性 → 樣本外驗證 | 依順序研究，保留資料警訊與無候選結果 |
| 組合多個策略 | 策略投資組合 | 選定策略及樣本外工作，建立版本並執行組合研究 |
| 整理交易決策與實際成交 | 交易日誌 | 先建立計畫，交易後手動記錄成交 |
| 規劃長期投入與退休 | 財務規劃 | 完成七步設定，比較試算，再儲存情境 |

頁面上方導覽分為「市場研究」、「策略研究」與「個人決策」。個股頁可由搜尋列或股票表格進入。第一次使用可先完成市場研究；策略研究需要額外準備較長的歷史資料。

## 3. 資料準備與每日檢查

### 首次建立資料

如果資料庫已經有資料，先檢查日期與缺漏，不必每次重新做完整初始化。空白資料庫則到「儀表板 → **資料維護與回補工作**」，依序執行：

1. **同步股票清單**：建立股票與 ETF 基本清單。
2. **更新今日行情**：取得每日收盤、估值、法人與大盤資料。
3. **回填 180 天歷史**：補齊均線與歷史篩選需要的資料。
4. **抓全市場月營收（13 個月）**：準備營收成長與轉機篩選資料。

回補時間取決於資料量與來源回應；請查看工作狀態，避免重複建立同一範圍的工作。開啟個股時，較深入的財報等資料會按需取得，可能需要稍候。

### 每次使用先看資料狀態

儀表板會顯示資料日期、預期交易日、缺漏日期及更新狀態：

| 畫面狀態 | 代表什麼 | 可以怎麼做 |
|---|---|---|
| 已同步 | 每日行情輕量層通過目前的完整性檢查 | 仍確認個股及研究資料的日期 |
| 待更新 | 資料落後 | 點「立即更新今日行情」並查看結果 |
| 更新中 | 工作正在執行 | 等待並觀察進度 |
| 部分資料未完成 | 已取得部分資料，但仍有缺漏 | 查看缺漏日期與錯誤，必要時再補齊 |
| 更新失敗 | 更新未成功 | 依錯誤確認來源與服務狀態，再重試 |
| 無法確認 | 暫時無法確認資料完整性 | 保留判斷，待來源恢復後再檢查 |

平日盤後會自動檢查並嘗試補齊每日資料；每月 10–12 日排程取得月營收。服務未執行時，排程不會運作，下次啟動會嘗試補齊，但仍要以最後顯示的狀態為準。全新空白資料庫需要先手動準備資料。

**每日更新取得的是盤後資料。** 觀察名單的「更新盤中報價」是另外的功能；每日「已同步」也不表示策略研究的歷史資料或研究基準已同步完成。

### 策略研究的歷史資料

到「資料維護與回補工作 → **Strategy Lab 資料基礎：5 年歷史回補**」：

1. 設定開始／結束日期與近一年日均成交金額門檻；預設門檻為新臺幣 3,000 萬元。
2. 點「建立回補工作」。建立後還需要執行工作。
3. 選取該工作，點「續跑 25 個單位」，查看資料覆蓋、進度與錯誤。
4. 一批結束後可繼續同一個工作；要暫停時點「完成本單位後暫停」。

完整歷史回補可能需要較長時間，請保持服務執行。中斷後選原工作續跑。若結果是 `completed_with_gaps`，代表工作處理完成但部分來源無資料，不能當成所有研究資料都齊全。

## 4. 市場與個股研究

### 儀表板

查看大盤走勢、成交量、三大法人、市場寬度與觀察名單速覽。先確認資料日期，再解讀數字；休市日或資料尚未補齊時，畫面可能仍是較早的交易日。

### 篩選器

1. 選營收動能、轉機、價值存股或突破等預設條件，也可以自行調整。
2. 填入營收年增率、本益比、殖利率、股價淨值比、法人連買、成交量等條件；**留空表示不限制該條件**。
3. 視需要勾選均線、營收轉正／加速或排除 ETF。
4. 點「執行篩選」，排序結果並開啟個股深入研究。

營收篩選需要月營收，均線等條件需要足夠歷史資料。沒有命中時，先確認資料是否齊全，再有意識地調整條件。篩選結果是研究候選清單。

### 個股頁

透過代號／名稱搜尋進入個股，依序查看：

- **K 線與均線**：價格、成交量與趨勢。
- **月營收**：營收變化、年增率與成長延續性。
- **獲利能力**：獲利及相關指標。
- **財務品質**：財報與現金流證據。
- **估值**：本益比、殖利率等比較資料。
- **籌碼**：法人與其他籌碼變化。

右欄提供系統證據、評分、警訊及治理查核清單。量化評分可作為起點，質化判斷仍需自己填寫；必要時覆寫分數並保留理由。缺資料或顯示「—」表示未知，不代表數值為零或沒有風險。

資料需要補抓時可點「重新抓取資料」。上方選單可將股票加入「研究中」、「等買點」、「持有中」，或移出名單。

### 觀察名單

使用三級分類與筆記記錄下一步要確認的事情。點股票可回到個股頁；「更新盤中報價」會取得當下可用報價，來源與即時程度依設定而異，無富果金鑰時使用延遲快照。

**「持有中」是追蹤分類。** 要讓交易日誌計算實際持倉，仍須在日誌記錄成交。

## 5. 策略研究：從回測到組合

建議順序：**單次回測（Backtest）→ 參數穩健性（Optimization）→ 樣本外驗證（Walk Forward / OOS）→ 策略投資組合（Strategy Portfolio）**。

### 第一步：策略實驗室

點「建立新策略」，從品質 × 成長 × 動能、營收成長加速、動能與趨勢、價值 × 品質、低波動 × 品質等模板開始。依畫面步驟設定研究範圍、因子與參數、組合規則、再平衡、交易成本、資料與公告模式，最後確認並執行回測。

- 設定研究日期、初始資金與基準；交易成本包含手續費、稅與滑價假設。
- 公告模式的「嚴格」（Strict）只使用實際或已觀察到的公告日期，資料可能較少；「假設」（Assumed）允許法定期限假設，需連同警訊解讀，不能視為已證明嚴格無前視偏誤。
- 結果要一起看報酬曲線、回撤、成交明細及資料警訊，避免只看單一績效數字。
- 修改策略定義會建立新版本；舊回測仍保留當時版本。

### 第二步：參數穩健性

由策略結果或模板基線建立研究，設定訓練區間、目標與搜尋範圍，點「建立並執行」。這一步用來觀察參數附近是否有穩健區域，結果屬於**樣本內（IS）探索**，不會選出保證可用的「最佳策略」。

閱讀參數分布、穩健區域與資料品質。若要擴大搜尋範圍，應保留為新的研究修訂，避免混淆兩次不同的實驗。

### 第三步：樣本外驗證

由策略或參數研究結果建立樣本外工作，設定訓練／測試區間與移動方式，再確認執行。每個驗證單位（fold）依序進行「訓練 → 凍結候選 → 樣本外測試」。

- **獨立 fold 的 OOS 結果是主要證據**；縫合（stitched）曲線是次要參考，不能當作同等獨立證據。
- `no_candidate` 表示該單位找不到穩定候選，會持有現金並保留紀錄，是有效結果。
- 看各單位的分散程度、可用候選比例與警訊，不只看總報酬。
- 看到 OOS 結果後再修改參數，是新的研究設計，不能繼續當成原本未受影響的測試。

### 第四步：策略投資組合

1. 點「建立投資組合」，依「基本資料 → 研究元件 → 配置方法 → 無候選政策 → 限制條件 → 確認版本」完成設定。
2. 每個元件選定策略與其已完成的樣本外工作；組合可以包含不同數量的策略。
3. 使用等權配置（equal weight）、固定權重（fixed weight）或有足夠證據的反波動配置（inverse volatility）。固定權重未分配的部分留現金。
4. 儲存版本後，到「研究紀錄」設定日期，執行該版本的研究。
5. 查看報酬、現金、聚合持股、換手、交易成本與警訊。

無候選元件預設留現金，不會自動把資金轉給其他策略。反波動配置證據不足時會停止並標示；風險平價、最小變異與相關性感知配置目前未實作。再平衡只支援每月；產業權重限制目前僅供報告，不會強制執行。

持股表是再平衡當日的研究快照，不是你的實際持倉或即時持股。修改組合用「建立新版本」；「複製」建立另一組合；「封存」保留歷史。研究版本及結果不會隨新設定改寫。取消後續跑會依原定義重新計算整個窗口。

## 6. 交易日誌：計畫與實際紀錄

先填「買進前八句話」，整理理由、成長證據、市場預期、自己的判斷優勢、已反映的成長、催化劑、失效條件與風險／部位。「帶入系統草稿」可協助部分欄位，請閱讀並改成自己的判斷。

填入股票代號、持有期間、進場／停損／目標價及最大可承受虧損，查看建議股數後點「建立交易計畫」。這只儲存計畫。

實際交易後使用「記錄成交」，輸入買賣方向、日期、股數與價格，必要時關聯原計畫。持倉與未實現損益依記錄計算；勝率等績效以已實現交易為基礎，成本依設定估算。漏記或輸入錯誤會影響結果。

## 7. 財務規劃：長期投入與退休試算

先選擇既有「情境」或「新增情境」，再完成七步：

| 步驟 | 填寫重點 |
|---|---|
| 1. 個人基本資料 | 年齡、收入與基本條件 |
| 2. 目前財務狀況 | 現金／存款與既有投資；確認金額避免重複計入 |
| 3. 投資目標與金額 | 初始投入、每月投入與目標，可自行調整建議值 |
| 4. 風險承受能力 | 完成問卷，必要時明確手動調整 |
| 5. 投資組合 | 選 ETF、自訂來源或策略投資組合，設定配置 |
| 6. 試算假設 | 保守／基準／樂觀報酬、通膨、費用、股息再投入等 |
| 7. 退休設定 | 以今日購買力估計支出，填退休收入及提領條件 |

輸入會更新畫面試算，**完成後仍要按上方「儲存」**。要比較不同規劃，分別建立情境。ETF 歷史不足時可使用「補齊 ETF 歷史資料」。

### 將策略投資組合納入規劃

在投資來源中選「策略投資組合」，指定組合、確切版本及需要查看的已完成研究，閱讀歷史證據，再明確設定報酬假設，點「確認來源與假設」，最後儲存情境。

選擇研究來源不會自動將歷史年化報酬填進規劃。即使選擇採用研究數值，它仍是你明確選定的假設。策略組合的實際金額需手動填寫或保留空白，不能把回測資金當成真實資產；組合內部現金也不等於你的個人存款。

策略組合新增版本後，已存的規劃不會自動更換來源；要採用新版本，使用「重新連結」並重新確認假設。

## 8. 常見問題與結果判讀

**資料空白或日期很舊？** 先看儀表板狀態與缺漏，再確認該功能需要的是每日、月營收、個股深度或研究歷史資料。每日更新不會補齊所有研究資料；空白也不等於零。

**研究顯示證據不足或嚴重警訊？** `insufficient_evidence`／`unavailable` 表示目前資料不支持該方法，不會自動改用別的方法。未解析的公司行動可能使研究出現嚴重（critical）資料品質警訊，必須連同結果閱讀。

**長時間工作中斷？** 先確認服務仍在執行，回到原工作查看狀態並使用可用的續跑功能。歷史資料回補可沿用同一工作；策略組合研究續跑則重新計算原窗口。

**登入失敗？** 確認私人網站帳密。持續出現未授權（401），請管理者確認帳密；服務未就緒（503）則需要管理者檢查部署設定與啟動狀態，參考 [部署紀錄](docs/railway-deployment.md)。

**手機能用嗎？** 可瀏覽與操作；較寬的表格可橫向捲動。複雜策略設定與多項結果比較適合在較大螢幕進行。

| 名詞 | 在本平台的意思 |
|---|---|
| 年化報酬（CAGR） | 歷史期間換算的複合年成長率，並非預測 |
| 最大回撤（Max Drawdown） | 從歷史高點到後續低點的最大跌幅 |
| 夏普比率（Sharpe） | 衡量歷史報酬相對波動的指標 |
| 樣本內／樣本外（IS／OOS） | 用來研究與選參數的資料／之後驗證的資料 |
| 時點資料（Point-in-time） | 在當時可知的資料；公告日期假設需另行揭露 |
| 無候選（no_candidate） | 未找到穩定候選，保留紀錄並持有現金 |
